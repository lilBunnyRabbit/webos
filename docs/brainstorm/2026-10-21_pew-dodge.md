# Pew Pew Dodge
**Date:** 2026-10-21
**Participants:** owner, Claude

## Context
LaxDOTexe (Proposals app): "you can choose to play a game with the desktop animation of lazers - they try to hit you like always, but you have to try and not get hit - the longest you last the higher your score - can be played on desktop - shows highest score in the corner, always resets your game the moment you get hit, never ending game that you don't have to play, but will still be recorded in the corner." Phone: "it doesnt matter on phone".

Today: Pew Pew (ADR-057, `src/lib/core/components/desktop/live/turrets/`) has Shield (windows are walls, `sim.ts:267` shelters the cursor) and Follow (bolts fly over windows). The sim already counts cursor hits (`sim.ts:306`).

## Decisions
- **Third mode, Dodge.** Mode becomes Shield | Follow | Dodge. Dodge fires like Follow (overlay layer, no shelter) and shows the score. Damage stays Shield-only. Rejected: a Score switch in both modes; a Game Hub card (couples Game Hub to the wallpaper).
- **Only exposed time counts.** The clock runs while the cursor is on the page and the tab is visible; it pauses when the cursor leaves the page or the tab hides, and a hit resets it to zero. Rejected: wall-clock since the last hit (idle time farms a score).
- **Best time in `/var/lib/desktop/pew.json`** `{ version: 1, best_ms, at }`, written when a run beats the best (debounced). In OPFS, so backups carry it. Rejected: inside the wallpaper options in settings.json (a game stat rewritten in settings); memory only (Lax wants it recorded).
- **Corner HUD:** current time and best, small, pointer-events none, theme tokens.
- **Shell:** nothing.
- **Mobile:** none; live wallpapers are desktop only.
