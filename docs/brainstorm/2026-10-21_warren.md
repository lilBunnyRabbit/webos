# Warren, a word processor
**Date:** 2026-10-21
**Participants:** owner, Claude

## Context
LaxDOTexe (Proposals app, "Not Google Docs"): "I need to write a CV/Resumé! I have no access to a word document without being forced to pay for basic features!" Wants font size, bold, italic, bullets, headings; character and word counts; change every occurrence of a selected word in one click; tools on the left in collapsible categories, the page on the right (sketch: narrow tool column, page centred); page size; user-placed page breaks or a never-ending page; misspelt words in a list with jump and ignore all; thesaurus for repeated descriptive words; open and save .doc and .pdf. Name: rabbits and writing, like Hopsprite.

Investigation: no rich text anywhere in the repo. Reusable: `print_html` (`core/utils/print.ts:10`) and Markdown PDF's `@page` CSS (`markdown-pdf/layout.ts:224`); `write_zip` (`core/utils/zip/write.ts:139`); `kit/utils/history.ts`; AiService `extract`/`prompt` (desktop only). JS can't read Chrome's spellcheck results. Thesaurus data is multi-MB (Moby, WordNet, MyThes).

## Topics discussed
### Engine: Lexical (decided)
Owner liked Lexical before; checked 2026-10-21: maintained by Meta, nightlies daily, 0.52.0, framework-agnostic core (`createEditor` + `setRootElement`), no React needed. App-scoped dependency (ADR-045), exact version pinned since 0.x minors break. Rejected: own model on `beforeinput` (1.5-2.5k lines, Android IME risk); `execCommand` (messy markup rots).
### Format: `.warren` JSON, export .docx and PDF (decided)
`{ version: 1, page: { size, flow }, editor: <Lexical state JSON> }`, zod-validated envelope, saved in /home with a file association. Export .docx hand-written into `write_zip` (headings, bold, italic, size, bullets, page breaks, page size) and PDF through `print_html`. Rejected: .docx native (import parser in the first cut, lossy round-trip); HTML. Not doing: `.doc` binary; PDF import (lossy). .docx import deferred.
### Spelling: native underline only (decided)
`spellcheck` on; Chrome draws the squiggles. Lax's error list, jump and ignore-all are out of this cut. Rejected: nspell + dictionary (~200 KB gz dependency); Nano proofreader.
### Thesaurus (decided)
Repeated descriptive words counted locally on both platforms; synonym suggestions through AiService on desktop, hidden when AI is unavailable. Rejected: Datamuse (a third-party server gets the user's words).
### Pages (decided)
Page size A4, Letter, A5. Each part between user breaks is a sheet at least one page tall that grows; a Continuous toggle drops the sheet chrome. Print honours breaks; an overlong sheet flows onto extra printed pages. Rejected: automatic fixed pages (JS measuring and splitting).
### Name (decided)
Warren, id `warren`, extension `.warren`.
### Shell (decided)
File association (`open x.warren`), plus `doc count <path>` (words, characters) and `doc export <path> --docx`.
### Mobile (decided)
Wide container: Lax's layout. Narrow: the sidebar folds into a sticky formatting bar (B, I, heading, list, more), and "more" opens the groups in a sheet.
### Replace all (decided)
Select a word, "Change everywhere" replaces every whole-word occurrence, one undo step.

## Key takeaways
