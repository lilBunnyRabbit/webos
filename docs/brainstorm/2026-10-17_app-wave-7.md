# App wave 7: the owner's picks

**Date:** 2026-10-17
**Participants:** owner, Claude

## Context

Follow-up to [app wave 6](2026-10-17_app-wave-6.md). The owner asked for a concrete plan per app (what it is, what it solves, size, how to build) as a page to pick from. Two investigations fed it: one mapped the 27 wave 6 ideas onto existing code (reuse, missing pieces, mobile, shell), one looked for new ideas in the owner's repos, notes and Chrome's built-in AI. The page listed 55 ideas, 7 bundles and 9 cross-cutting decisions; the owner answered Yes / Maybe / No with notes.

## Answers to the owner's questions

- **On-device AI.** Summarizer, Translator and Language Detector are stable in desktop Chrome (since 138); the Prompt API (Ask) is listed stable in Chrome 148. They run Gemini Nano locally after a one-time model download, so it's private and works offline. Not on Android Chrome, so phones get no AI. Language support for Slovenian has to be checked on the owner's Chrome. Possible on desktop; the core service would expose availability so apps hide the feature where it's missing.
- **Party Controller.** Possible, but the hard part is signaling with no backend. WebRTC peers must swap an offer and an answer before the data channel opens. Options: a two-way QR exchange (phone scans the TV, the TV's camera scans the phone back; awkward on a TV), a public signaling broker (a third party and likely a dependency), or sound (Chirp) for the answer. The smallest step that needs none of that is the Gamepad API in one game.
- **Stego Lab.** Hides text or a file in an image's low bits and shows bit planes. No real use beyond learning the format and CTF-style puzzles; fine to drop.
- **Redline.** A design-QA tool, not a text diff: grab a tab, then measure gaps and sizes with edge-snapping rulers, pick colours, export an annotated PNG to check a build against Figma.

## Decided: Image Compare (Image Tools section)

- **Placement:** its own Compare section. Patch's two-image load, align and diff move into a shared `ImagePair` class (`pair.svelte.ts`) that Patch and Compare both use. Against it, noted: it refactors Patch right after its phone fixes.
- **Views:** wipe slider, onion skin, diff heatmap; stats (changed %, regions, offset, scale).
- **Shell:** `imgdiff <a> <b>` yields a record with the stats; `--open` opens the Compare section.

## Decided: Redact, Squash, Poster Print (Image Tools sections)

- **Redact:** box, pixelate and blur, with blur forced heavy (radius at least 20 px) and a minimum pixel-block size, since weak blur and small blocks can be undone. Saving re-encodes, so metadata goes. Shell: none, choosing areas is visual.
- **Squash:** a section with a per-file savings list, run as a task with one task per file; WebP or JPEG, no AVIF (it would need a WASM encoder dependency). Shell: `squash <paths…> [-f webp|jpeg] [-q N] [--max N] [--to dir]` yields the written files.
- **Poster Print:** a section writing one PDF through `pdf-tools/pdf.ts` (cross-app import, as Calendar does). A3 joins A4 and Letter in PAPER. Shell: `poster <path> [-x N] [--paper a4|letter|a3] [--overlap 10mm] [--landscape] [-o out.pdf]`.

## Decided: Metadata Inspector (new app)

- **Core:** `core/utils/exif/` is a reader only: `read_metadata(bytes)` for JPEG, PNG and WebP, plus `orientation(bytes)`, which also fixes PDF Tools' JPEG orientation bug. Stripping stays in the app, the only writer.
- **App:** a new Metadata app reached through Open with for images and PDFs: grouped table, map link for GPS, raw bytes in Hex Viewer, strip and save without re-encoding.
- **Shell:** `meta <paths…>` yields one record per file as columns; `meta strip <paths…> [--keep-orientation]` writes stripped copies.

## Decided: shell and dev batch

- **`file` command:** in Hex Viewer's manifest next to `hexdump`. Magic-byte table, text detection (UTF-8, BOM, line endings), Shannon entropy; `--scan` lists files embedded inside others, and clicking one opens Hex Viewer at that offset. Yields columns. No entropy strip in the Hex Viewer UI for now.
- **Dev Tools tabs:** JWT (decode, HS256 verify), timestamps, cron (next runs, plain English), X.509 certificates. YAML to JSON skipped: a subset parser over `@lezer/yaml` would get anchors and block scalars wrong, and the `yaml` package is a new dependency.
- **Dev Tools shell:** its first shell block, one command per tab, all reading stdin: `jwt`, `ts`, `cron`, `cert`, `b64`, `hash`, `uuid`.
- **wget and `http`:** owned by a new API Client app through its manifest, sharing the app's fetch-to-file task. No core change; the cost is that wget goes if API Client is removed.
- **API Client requests:** saved as `.http` files (the REST Client format), which open in API Client and edit in Text Editor.

## Decided: games batch

- **Score dailies:** extends ADR-035. A daily entry becomes `{ ms, score? }`; a game's manifest declares how its daily ranks (`time`, `score-asc`, `score-desc`, time breaking ties). Old `plays.json` files stay valid; Game Hub shows the score with the time.
- **Crack the Code:** port of `playground/crack-the-code` as a game with a daily ranked by fewest guesses. No shell.
- **Jigsaw:** no daily; any picture opened through Open with or picked in the game. No shell.
- **Image to Nonogram:** a "From image" import in Nonogram's editor only (size, 2–4 colours, threshold), flipping cells until `analyze` finds one solution. No command, no Open with.

## Decided: real folders and the three sources ([ADR-044](../adrs/044-folder-mounts-and-sources.md))

- **Model:** FilesService mounts a picked folder at `/mnt/<name>`; Explorer, shell and apps work on paths unchanged. The owner picked it over a source union returned to apps, which keeps FilesService untouched but hides real folders from Explorer and the shell.
- **Persist:** handles in IndexedDB (new, mounts only); locked after reload, one click reconnects. Backup and session skip `/mnt`.
- **Picker:** the OS picker sheet gets "This device…" (copies into `/tmp/device/`, returns paths, API unchanged) and "Folder on disk…". The 37 per-app "From device…" buttons go.
- **Upload:** Upload files…, Upload a folder… (copy), Mount a folder (no copy)….
- **Delete:** inside `/mnt` always confirms with permanent wording; `rm` needs `-f` there.
- **Shell:** `mount`, `umount <path>`, `mounts`.
- **Build after** the running app builders merge: it touches the picker and every app's Open buttons.

## Decided: Disk Usage and Bulk Rename

- **Disk Usage:** a treemap in Activity Monitor › Storage (tap to drill in, Reveal in Explorer). FilesService gains `size_tree(path, depth?)` returning `{ name, path, size, children? }`, a public API change, cached by revision (ADR-021); `du -d N` yields child rows. Works on `/mnt`.
- **Bulk Rename:** Explorer's Rename with several files selected opens a sheet with a pattern (`{name}`, `{ext}`, `{n:3}`, `{date:…}`, `{parent}`, find and replace, regex) and a live preview. FilesService adds `rename <pattern> [paths…] [--dry]`, taking piped files; the pattern engine lives in core files.
- **Safety:** the preview blocks clashes up front; renames run in two phases (temporary names first) so swaps work; a failure renames the finished steps back. No general undo system.
- **Build after** ADR-044 lands: both touch FilesService and Explorer.

## Decided: design and QR batch

- **Atlas Packer:** an Image Tools section; frames in natural name order, so no reorder component. MaxRects packer, trim, padding, extrude, power of two; PNG plus JSON (TexturePacker hash) or CSS, zipped. No shell.
- **Icon Pack:** a new app, Open with for SVG and images: preview grid (tab, iOS, Android masks, light and dark), safe-zone overlay, OG card composer, hand-written ICO writer, zip. Shell: `icons <svg> [--bg] [--padding 10%] [--to dir]`.
- **SVG Workbench:** uses SVGO (`svgo/browser`, lazy), as a dependency scoped to the app through Bun workspaces ([ADR-045](../adrs/045-scoped-app-dependencies.md)): the owner's "apps package.json" idea, the roadmap's scoped app dependencies. Shell: `svg optimize|png|component <path>`.
- **QR Studio:** its own hand-written encoder, tested against `uqr`; core `qr.ts` keeps `uqr` until the encoder is proven, then swaps in its own change (P2P pairing depends on it). Shell: `qr "text" [--ecc L|M|Q|H]` yields an image.

## Decided: last batch

- **On-device AI:** an `ai` core service ([ADR-046](../adrs/046-on-device-ai-service.md)) with availability, summarize, translate, detect and prompt; downloads as tasks; an unavailable variant on mobile. Shell `summarize`, `translate --to`, `lang`. An Ask app chats about an open file.
- **Funky DSL:** the owner wants it improved, not just ported ("not in ideal state now, just a poc"). An investigation lists upgrades first, then a grill, then the build.
- **Keyboard & HID Lab:** ShortcutsService gains `suspend(): () => void` (public API change) so the key tester receives every key while focused; browser-reserved keys still can't be caught. WebHID inspector with a hand-written report descriptor parser. Shell `hid ls`.
- **Web app wrapper:** `.webapp` shortcut files (name, URL, icon) open in a window with an iframe; when a site refuses framing, the window says so and offers to open it in a browser tab. Shell `webapp add <url>`.
- **Recipe Box:** Cooklang `.cook` files (ingredients, cookware and timers marked inside steps), hand-written parser; ingredient list, scaling, cook mode with timers and wake lock, and the Cooking for Engineers table derived from the same text.
- **GW2 Tracker:** built despite the 2026-10-14 triage rule against external APIs and keys, by the owner's call: key in `app.gw2.*`, dailies, wallet, crafting goals, cached responses. Shell `gw2 daily`.
- **Video Tools:** play-and-capture first: a hidden `<video>` with `requestVideoFrameCallback` feeds WebCodecs (WebM out through a muxer the app owns) or the GIF encoder. Real-time speed, any format Chrome plays, no demuxer. Shell `video trim|gif`.

## Decided: Funky DSL, ~/dev finds, lazy shell

- **Funky DSL v1:** port the compiler and fix what the investigation found: setter XML format checked against a real craft save (the builder searches the SimplePlanes save folders on this Mac), `@prev` ordering, `Pitch--3`, missing built-ins (`GForce`, `GearDown`, …). CodeMirror language (highlight, lint gutter, completion, hover), source-level diagnostics with recovery, craft XML import decompiled into the DSL, `.fdsl` files, examples, simulator presets and graphs, per-setter copy. Deferred: part, priority and activator syntax (own grill), types, imports, plant model. No shell.
- **CodeMirror deps:** `@codemirror/autocomplete` and `@codemirror/lint` become direct root dependencies for the core code module, since any app's editor can use them; scoping them to one app risks two CodeMirror state instances.
- **Forms** (from `playground/formlink`): `.form.md` opens in a Forms app (Build, Fill, Answers); forms and answers travel in WebOS deep links. Shell `form link <file>`.
- **Quests:** a Kanban board backed by a folder of markdown files, columns from a frontmatter field, new cards from a template. Waits on ADR-044 mounts for the real vault.
- **Link Preview** (from `tools/meta-testing`): its own app; Slack, X, Facebook, Discord, LinkedIn and iMessage cards plus checks, from an HTML file, pasted HTML, or a URL where CORS allows (no server). No shell.
- **Lazy app shell commands:** `define_app({ shell: () => import("…") })`, loaded the first time Terminal or the palette opens; ~10 KB of the ~33 KB of manifests at boot. Revises ADR-034. Built after the running app builders merge, since it touches every manifest with commands. Built 2026-10-17: every manifest's `shell` is `() => import("./commands")`; entry chunk 190.5 → 182.3 KB gz.

## Decided during the builds

- **Compound extensions:** association entries with two dots (`.form.md`) match the end of the file name and rank above a plain extension, and a remembered `.md` default doesn't override them (ADR-018 revision). Built by the Forms builder without asking; the owner kept it.
- **Boot budget:** at 190.5 KB after the AI service; lazy app shell commands bring it back down before any push.

## Decided after the mounts landed

- **Multi-pick:** the picker gains `multiple: true` (ADR-025 revision); "This device…" then copies several files into `/tmp/device/`. Restores picking many device files at once in Squash, Atlas, Join, Compare and Patch, PDF Merge and Images, Soundboard and Diff.
- **Device-button exceptions:** P2P Transfer, Archive create, Dev Tools Hash and Hex Viewer keep their own button (big files stay in memory); Recipe Box and Brackets keep theirs (import into their library). Video Tools and Funky lose theirs.
- **Kanban folder boards:** the optional `folder` field in `boards.json` stays; the shell reaches folder boards (`kanban ls`, `mv`, `add`).
- **Release:** 2.0.0, since the lazy shell commands removed the eager `shell: {…}` manifest form from the stable app API.

## Decided: app icons

- Every app gets its own SVG icon (`icon.svelte` beside its manifest), drawn in four rounds plus a core polish: rounded 1.5 px line in the text colour, one idea per app, colour only on the element the app is about and only outside the line drawing (18 of 76). Kernel is a brain again, redrawn in the house style. Rules in `docs/design/foundations.md#app-icons`.
- Swapping the Phosphor app icons out dropped the boot chunk from 186.4 to 159.0 KB gz.

## Decided: GW2 inventory (2026-10-18)

- Owner missed a one-page inventory of every character; no older project held it, so it's built new.
- One key; places are Bank, Materials, Shared slots and each character (bags plus equipped gear, marked). No legendary armory, delivery box or guild storage.
- Grid of item tiles, rarest first, with search (name or id), type, rarity and sort filters; tapping a tile shows where each count sits.
- Rarity uses the game's own colours, scoped to the GW2 app: an owner-approved exception to theme-tokens-only.
- Shell: no command; the app takes `section: "inventory"` and a `query` prop.
