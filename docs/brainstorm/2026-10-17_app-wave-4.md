## Decisions

### Picked for this wave

Wordle and variants, Sokoban, Blocks, Hex Viewer, Font Viewer. Chess, Spreadsheet, Video Tools and the Web app wrapper stay later.

### Wordle

- English only. Two lists per length (5, 6, 7): a curated answers list of common words and a larger allowed-guesses list filtered from ENABLE (public domain). Loaded in Wordle's own chunk, never at boot.
- Variants, all of them:
  - lengths 5 / 6 / 7
  - multi-board: Dordle (2), Quordle (4), Octordle (8), one guess on every board, guesses = 5 + boards
  - Nerdle: 8-character equations, generated from a seed, own keyboard `0-9 + - * / =`, a guess is valid only if it parses and both sides are equal
  - Absurdle: adversarial, keeps the largest bucket of remaining words after each guess
  - Hard mode (revealed hints must be reused) and Survival (a run of words, hints carry over)
- Daily through the `daily` prop like Minesweeper, so Game Hub picks it up.

### Sokoban

- Generated levels, not a bundled set: seeded generator (carve room, place goals, reverse-pull boxes) with a solvability check. Daily = seed from the date.

### Blocks

- Falling blocks (Tetris-like): line clears, levels speed up, hold and next queue. Daily = seeded piece order.

### Hex Viewer

- Windowed rows: only visible rows render, bytes read through `Blob.slice`, any file size. JS scroll handling accepted by the owner for this case.
- Association: in Open with for every file, never the default.

### Font Viewer

- Native `FontFace`, no dependency. Default for `.ttf`, `.otf`, `.woff`, `.woff2`.

### Shell

- `wordle daily [day]`, `sokoban daily [day]`, `blocks daily`, following `minesweeper daily`.
- `hexdump <path> [--length N]` yields text rows; clicking a row opens Hex Viewer at that offset.
- Font Viewer: no command (`open` covers it).

## Key takeaways

- Every game here fits the existing Game app pattern and the `daily` prop; nothing new in core is expected.
- Hex Viewer is the first app with windowed rendering; if a second list needs it, it becomes a kit question.
