# AI games: Unsaid (Taboo), Sketch Guess, Alibi
**Date:** 2026-10-21
**Participants:** owner, Claude

## Context
Owner: "Run subagents for a few of the ai apps you think are best." Picked from [AI-native apps](2026-10-20_ai-native-apps.md): Taboo (research pick #1), Sketch Guess (#2), Alibi. Three investigate-only reports. Shared findings:
- AiService (ADR-046): `prompt()` streams and keeps up to 4 chat sessions OS-wide (`service.svelte.ts:23`); `extract()` validates JSON against a zod schema but is text-only (`:174`) and uses a fresh session per call.
- `MobileAiService` answers no to everything; the manifest has no platform field. Ask shows an unavailable `EmptyState` (`ask.app.svelte:216`).
- Game Hub gives any game with a `daily` prop a daily row, with no availability filter (`game-hub/hub.ts`).
- Each game keeps rules and judging in code; the model only guesses or talks.

## Topics discussed
### Phones (decided)
Unavailable screen like Ask: the apps open on phones and say they need on-device AI. No API change. Rejected: a desktop-only manifest flag (public API change, needs an ADR); no-AI pass-and-play modes (a second game each).

### AI availability gate (decided)
Moves to the kit as a component now, used by Ask and the three games, with the Style Guide and design docs updated, in its own `refactor:` commit first. Rejected: a copy per app (4 copies drift).

### Image call for Sketch Guess (decided)
`extract()` accepts image content: with an image it opens a `prompt-image` session with `expectedInputs` plus the schema, and destroys it after the call, so it never evicts kept chats. Revision note on ADR-046 and ADR-051. Image plus `responseConstraint` is unverified, so the builder checks it first. Rejected: `prompt()` plus text parsing (every guess evicts other windows' chats); a kept base session plus `clone()` (new service API).

### Dailies (decided)
None for now, Alibi included. Prove the loops first. Rejected: Alibi only; all three (model variance makes scores soft; a dead daily row on phones).

### Names (decided)
Rabbit-themed: **Unsaid** (`unsaid`, the Taboo game; "Taboo" is a Hasbro trademark and the site is public), **Doodlehop** (`doodlehop`, Sketch Guess), **Alibi** (`alibi`). Rejected: Sketch Guess as the name (plainer); Taboo (trademark).

### Unsaid (decided)
Round of 5 cards, untimed. About 150 hand-written cards `{ word, banned: [5], category }` in our own wording, lazy-loaded. After each clue one `extract()` call returns 3 ranked guesses; the prompt carries every clue so far plus the wrong guesses. Banned words are checked in code (lowercase, strip diacritics, split on non-letters, cheap English suffix strip, prefix match for stems of 4+ letters); a clue with a banned word or the target is blocked and never sent. A hit is any of the 3 guesses matching the target with the same normaliser. Score = clues used, Pass = +3, lower is better. `track_play` plus the best round score in app storage. Rejected: classic timed (latency eats the clock); AI-written banned words (code no longer owns the rules).

### Doodlehop (decided)
Quick, Draw! style: 6 words × 20 s. A raster canvas in the app (pointer capture, coalesced events, round caps, fixed width, Undo via `$kit/utils/history`, Clear). After each stroke ends, ~700 ms idle, one call in flight; strokes made meanwhile merge into the next snapshot. The snapshot is cropped to the ink, drawn black on white, scaled to 384–512 px, PNG. `extract()` with the image returns `{ guesses: z.array(z.enum(WORDS)).max(3) }`; the target is never sent; matching in code. A guess sent before the timer ends still counts. Recap grid of the drawings with the AI's last guess, Save PNG per drawing through `pick_save` (`~/Pictures/{word}.png`). Word list: ~150–250 concrete nouns, hand-picked. Score = words recognised, time breaks ties. Rejected: zen untimed; free guesses without the enum (needs an alias table, less accurate).

### Alibi (decided)
A few scenario templates with times, places, people and items filled from `create_rng(seed)`. Code writes 5–6 statements; one is flipped into the lie, code emits the evidence card that contradicts it plus neutral cards. The model gets a story-only sheet in the system prompt (the lie stated as fact, persona, "1–2 sentences, anything not on the sheet you don't remember"), never the evidence, so asking for the lie leaks nothing. Questions are free text through `prompt()` (kept session, streams). Accusation pairs a statement with an evidence card, 2 tries, judged by code. Score = questions asked + wrong accusations. Save and resume as seed + transcript + picks in app storage. A generator test proves exactly one statement contradicts exactly one card for many seeds. Rejected: hand-written cases (spent once seen); single pick with topic buttons (barely AI-native); the model inventing the case (no consistency, nothing to verify).

### Shell (decided)
No commands. Unsaid and Alibi take `{ seed?: number }` so a link replays the same cards or case; Doodlehop takes no props. Rejected: `doodle guess <file>`.

## Key takeaways
- Code owns every rule and every verdict; the model only guesses or plays a part.
- One kit gate for every AI app; `extract()` grows image input instead of games keeping chat sessions.
