# App wave 6: ideas in the Image Split direction

**Date:** 2026-10-17
**Participants:** owner, Claude

## Context

The owner asked for new app ideas pushed in the direction of what exists and what they've been thinking about, pointing at Image Split: "a very niche app but it was solving a problem i couldn't otherwise". An investigation read the app list, the roadmap, the brainstorm logs, the Obsidian `projects/ideas` notes and the owner's GitHub repos.

The pattern in the owner's own tools: gap-fillers for their dev and design work (test-images, chrome-safe-inset, logo-proof), image and video processing (static-utils, web-gif, game-clip), learning a format by writing it (zip, GIF, Huffman), private and serverless (P2P over QR). Each one is local, private, handles big files, previews visually, batches, and is scriptable.

## Ideas listed

Niche tools: Image Compare (slider, onion skin, diff heatmap), Poster Print (one image over A4 sheets as a PDF), Duplicate Finder (SHA-256 plus perceptual hash), Instant Replay (game-clip port: last 30 s of screen as WebM or GIF), Metadata Inspector and Stripper, Document Scanner, Redact, Disk Usage, Bulk Rename.

Dev tools: Brand Proof and Icon Pack (logo-proof built in), Data Lens (huge JSON, NDJSON and logs with windowed rows), SVG Workbench, Git Viewer (packfiles by hand), Dev Tools tabs (JWT, X.509, cron, timestamps, YAML), device frames in HTML Preview, API Client (CORS-only).

Media: Image Squash (batch WebP), Audio Tools, Subtitle Sync, Atlas Packer, Comic Reader (CBZ), EPUB Reader, `file` command (magic bytes, entropy), Stego Lab.

Games: Jigsaw, Typing Trainer, Image to Nonogram.

Open questions for any of them: `showDirectoryPicker` (Duplicate Finder, Disk Usage, Git Viewer) would make local-folder access part of the core, the owner's call.

## Decided: Patch (Image Tools section)

The owner's own idea: two versions of one picture, the original and an edited copy where the edit tool stamped a mark (its logo, "Made with X"). Restore the mark's area from the original, keep the edits.

- **Placement:** a section of Image Tools, not a new app.
- **Selecting:** a pixel diff finds the changed regions, shown as boxes with a tolerance slider; click a box to restore it, or drag a box or brush for anything missed. Real edits show up as diffs too, so the owner picks which to restore.
- **Alignment:** auto-align offsets and scale as well, not only same-size images, so cropped or resized exports still line up.
- **Shell:** none. Picking regions is visual.
