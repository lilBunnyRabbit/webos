# App font from Font Maker
**Date:** 2026-10-21
**Participants:** owner, Claude

## Context
Owner: "for the fonts i make i want to be able to set it as the app font. also while your at it make a cool font that is a good fit for the app. make it with the tool".

Today: `--font-sans: "Inter"` and `--font-mono: "Hack"` are fixed in `src/app.css:53-54`. Appearance settings (`settings/appearance.ts`) hold radius, motion, shadow, text size in `/etc/settings.json` (ADR-015). Font Maker builds TTF from `.fontmaker` projects (ADR-055, `font-maker/ttf.ts`); Font Viewer opens `.ttf/.otf/.woff/.woff2`.

## Decisions
- **Storage: copy into `/etc/fonts/`.** Choosing a font copies its file to `/etc/fonts/{name}.{ext}`; settings store the choice, not a `/home` path, so moving or deleting the original doesn't break it and backups carry it. Editing the font means applying it again. Rejected: referencing the `/home` path (breaks on move); pointing at the `.fontmaker` project (Font Maker only, build at every boot).
- **Two roles: UI font and code font.** `appearance.font = { sans: FontChoice, mono: FontChoice }`, `FontChoice = { kind: "default" } | { kind: "builtin", id } | { kind: "file", name }`. At boot SettingsService loads the chosen files with `FontFace` and sets `--font-sans` / `--font-mono` with the defaults as fallbacks. A missing file falls back to the default with a notification.
- **Ways in:** Font Maker "Use as app font" (UI or code), Font Viewer "Use as app font" (UI or code), Settings › Appearance › Font with two pickers (Default, built-ins, installed fonts in `/etc/fonts`, remove one, reset).
- **Shell:** nothing.
- **Built-in font "Burrow", made with Font Maker.** A monoline font drawn as a real `.fontmaker` project and built to TTF by Font Maker's own `build.ts`. The TTF ships in `static/` as a built-in choice; the project goes in the Getting Started samples to open and edit. Inter stays the default. A test checks the shipped TTF equals building the sample project, so they can't drift.

## Follow-up: families, weights and italic (decided)
Owner: "we need to think of font weight in the editor and italic and other styles. the maker should support all that".

Today `build.ts:13` outlines centre-line strokes at one width and `ttf.ts:164-170` names every font "Regular" (weight 400, no italic).

- **Weights derived from stroke width, with fixes.** A project lists its weights; each has a width multiplier (Light 0.6×, Bold 1.7×, editable). Any glyph can get a per-weight redraw (counters clogging in e, a, &). Owner's note: also allow drawing a weight fully by hand (every glyph redrawn for that weight, the editor switches weight) and a variable-font export.
- **Variable font export.** One TTF with a `wght` axis (fvar/gvar) across the listed weights. Works because the same strokes outlined at different widths can be made point-compatible (fixed sampling per stroke). A glyph whose weight redraw isn't point-compatible blocks the variable export; the export says which glyphs. Static faces are always available.
- **Italic: automatic slant plus optional redraws.** A shear by the project's slant angle (default 10°) for every weight; any glyph can get an italic redraw (single-storey a). The build sets italic in OS/2, head and name.
- **Faces:** pick any of 100-900; default 400 and 700, upright and italic (Regular, Italic, Bold, Bold Italic). Preview gets a weight picker and an italic toggle.
- **One file per family: TrueType Collection (`.ttc`)**, owner: "if possible - if not one ttf per face". Chrome's `FontFace` can't pick a face inside a collection, so WebOS splits the `.ttc` into single-face sfnt buffers when loading (a small reader rebuilds each face's table directory). Export writes `{Name}.ttc`; per-face TTF export stays available. Font Viewer opens `.ttc` and shows its faces.
- **App font = family.** `/etc/fonts/{family}.ttc` (or a single TTF/OTF/WOFF for a one-face font); `FontChoice = { kind: "default" } | { kind: "builtin", id } | { kind: "file", name }` names the family file; boot registers each face with `FontFace(family, buffer, { weight, style })` so CSS bold and italic use real faces.
- **Burrow** ships as a family: 300, 400, 700, upright and italic, as `.ttc`, plus the variable export if it passes.
- **Offline (owner, after review).** Built-in font files are not precached; a Workbox runtime rule caches `/fonts/*.ttf|ttc` CacheFirst in its own `webos-fonts` cache (200 only) on first use, so a built-in works offline once chosen. Settings keeps depending on `notifications` (owner OK).
