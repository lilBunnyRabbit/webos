# Tea Timer
**Date:** 2026-10-25
**Participants:** owner, Claude

## Context
Owner: "Tea timer. The timer should include a list of presets of all the common teas + a way to add custom presets. for example on the teas i have it says 95c 3-5min black tea, 95c 5-7min fruit tea"

Today: Clock's Timers tab has fixed minute buttons (`clock/timers-tab.svelte`) and rings through the scheduler as `clock:timer-{id}` jobs, with the label, length and paused time kept in `clock.json`. Recipe Box and Pomodoro use the same scheduler path. Nothing stores a temperature, a time range or named presets.

## Decisions
- **New app** `tea-timer`, "Tea Timer". The owner's own idea, so no extra credit. Rejected: tea presets in Clock's Timers tab (crowds Clock, and a temperature has no place there).
- **Teas:** built-in presets for the common teas (black, green, white, oolong, herbal, fruit, rooibos, pu-erh and so on), each with a temperature, a time range, an optional number of steeps with extra time per steep, and notes. Built-ins live in code; they can be edited or hidden but not deleted. Custom teas are added, edited and deleted.
- **Range:** a strength picker, Light / Medium / Strong, maps to the min / middle / max of the range. Medium is the default, and the app remembers the last strength per tea. It rings once. Rejected: two rings, ready then done; ringing at the min only.
- **Brews:** several at once, one per cup, like Clock timers. One scheduler job per brew, `tea-timer:brew-{id}`, so it rings with the window closed. Rejected: one brew at a time.
- **Re-steeps:** a tea can have steeps (for example green, 3 steeps, +30 s each). After a ring the brew offers the next steep with the added time.
- **Notes per tea:** free text (brand, amount, milk).
- **Units:** stored in °C, with a °C/°F switch in the app saved in the file. The custom tea form edits in the chosen unit. Rejected: °C only.
- **Storage:** app data file `teas.json` via `live_file`, following Clock's `clock.json`. It holds:
  - `version`;
  - custom teas, and edits to built-ins;
  - hidden built-ins;
  - the unit;
  - the last strength per tea;
  - brew extras: tea, steep and strength.

  Backed up and synced across tabs. Rejected: app storage (`app.tea-timer.*`).
- **Shell:** nothing. `app launch tea-timer` covers it, and scheduler notifications get no shell buttons (a body click opens Tea Timer). Rejected: `tea brew/ls/stop`, `tea brew` only.
- **Mobile:** both, as every app.
- **First cut:** presets, custom teas, strength, several brews, re-steeps, notes, unit switch. Not now: a desktop widget.

## Key takeaways
- A Clock-timer-shaped app with a tea model: temperature, range, steeps. No new service, no dependency.
