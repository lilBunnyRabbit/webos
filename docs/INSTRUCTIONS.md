## 🎯 Project Summary

- **Type:** Browser-based desktop OS (no backend)
- **Stack:** React 19 + TypeScript + Vite + Tailwind CSS 4
- **Storage:** OPFS (Origin Private File System) + localStorage
- **Current Phase:** Phase 1 complete (foundation), Phase 2 in progress (app ecosystem)
- **Architecture:** Two-layer (Core framework + Apps)

## 🔑 Key Systems

1. **Window Management** - Multi-window system with drag, resize, snap
2. **File System** - OPFS with TanStack Query integration
3. **Desktop Environment** - Icons, taskbar, start menu
4. **App System** - Extensible application framework
