Double-click an image, video or audio file in File Explorer, or press **Open…** and pick one. You can also paste a file with Ctrl+V.

## Images

- Zoom with the toolbar buttons or Ctrl + mouse wheel. On a touch screen, pinch to zoom and drag to move around.
- **Rotate** turns the view a quarter turn. It doesn't change the file.
- **Fit to window** puts the zoom and rotation back.
- **Set as wallpaper** makes the image your desktop background (not for JPEG XL).

**Save to disk…** downloads a copy of the file to your device.
