## Finding a page

- The side list groups every page. In a narrow window, open it with the list button at the top left.
- **Search** at the top of the list matches page titles and headings.
- From the Terminal or the command palette, `docs windows` or `docs adr 47` opens a page straight away.

## Reading

- Links between pages open here. **Back** (or Alt+Left) returns to where you were.
- **On this page** lists the page's headings; in a narrow window it's a button in the toolbar.
- The arrow button opens the page's source on GitHub.

## The map

**Map** in the side list draws WebOS as one picture. Drag to move, scroll or pinch to zoom, and click or tap a box to open its page. With the keyboard: arrows move, + and − zoom, 0 fits it all.
