Double-click a text file in File Explorer, or start typing in a new window and save it somewhere.

## Keys

- Ctrl+S saves, Ctrl+Shift+S saves as, Ctrl+O opens.
- Ctrl+F finds and replaces. Ctrl+Z undoes. Tab indents.

## Good to know

- Markdown files get **Edit**, **Split** and **Preview** views. Links in the preview open in a new tab.
- System files (in `/etc`, `/var` and `/tmp`) open read-only. **Save as…** keeps a copy you can edit.
- If another window changes the file while you have unsaved edits, a bar asks whether to reload or keep yours.
- Closing with unsaved changes asks whether to save first.
