Pick a page from the side list. Changes apply right away; there's no Save button.

- **Search settings** at the top finds any setting by name. Arrow keys and Enter jump to it.
- From the Terminal or the command palette, `settings text-size` opens straight at a setting.
- A theme saved under **Your themes** exports as a `.webos-theme` file from its ⋯ menu. Opening such a file offers to import it.
