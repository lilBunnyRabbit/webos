## The goal

Draw one path that starts on 1, passes every number in order and ends on the highest one. It has to fill every cell exactly once, moving up, down, left or right. Thick bars are walls the path can't cross.

## Drawing the path

- **Drag** from the end of the path to extend it. A fast drag fills the cells it skips.
- **Drag back** over the path to take steps back, or press any cell on the path to cut it back to there.
- A step that breaks a rule is refused, and the status line says why: a number out of order, a wall, or a path that already reached the last number.
- **Keyboard:** arrows extend the path from its end, and an arrow toward the previous cell steps back. Backspace also steps back.

## When you're stuck

- **Hint** (H) first takes back a step that went the wrong way. Otherwise it draws the next step, plus every step after it that has only one way to go.
- Undo and redo with Ctrl+Z and Ctrl+Shift+Z. F2 starts a new puzzle. On a phone, Undo, Redo and Hint sit under the board.
- Every puzzle has exactly one answer.

## Timer and daily

The clock starts when you press Start and pauses while the window is hidden. A puzzle you leave is kept, path and time, for next time. Best times per size count only solves without hints; the side panel shows them (the chart button on a narrow window). The daily is a 7×7 puzzle, the same for everyone, and Game Hub keeps your results.
