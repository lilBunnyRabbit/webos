## Capture first, sort later

- Press **Alt+Shift+Q** anywhere in WebOS to jot something down without opening the app. Pick **Note** or **Todo** and press Enter.
- New notes land in the **Inbox**. Open one, then set its status: **Ready**, **Done** or **Dropped**. The **Notes** tab lists them by status.
- **New note** starts an empty one in the Inbox.

## Writing notes

- The first line is the title. Type `#tags` anywhere; the filter box takes a `#tag` too.
- Write `[[another note]]` to link notes. Links and the notes that link back show under the text. A link to a note that doesn't exist yet creates it when you click it.
- Right-click a note in the list, or long-press it on a phone, for the status, delete and sticky options.

## Todos

The **Todo** tab is one checklist. Type a todo and press Enter, tick it off when it's done.

## Stickies

On the desktop, **Add to desktop** puts a note or the todo list on the desktop as a widget you can edit in place. Click it again to take it off.

## Where it's kept

Every note is a markdown file in `/home/Notes`, and the todos are `todo.md` there, so any editor can open them.
