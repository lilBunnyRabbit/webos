## Pick one

- Choose a group, then an algorithm from the row along the top.
- **How it works** opens the idea behind it, when to use it, and its best, average and worst cost.

## Give it an input

- Type an input and press **Run** or Enter. The line under the box shows the format it takes.
- The shuffle button rolls a random input. **Presets** has the telling cases, like already sorted or reversed.
- Some algorithms have extra settings under the input. Data structures have **Try it**: run one operation, like an insert, and watch just that part.

## Draw a graph or place points

- Graph and geometry algorithms have **Draw graph** or **Place points**. Press **Done** to watch it run on what you drew.
- Click or tap empty space to add, drag to move, and tap two nodes one after the other to connect them.
- Select an edge to set its weight. Select a node to make it the start or goal, when the algorithm has one.
- Keyboard: Tab to a node, arrows move it (Shift moves 10), Enter on two nodes connects them, Delete removes.

## Watch it

- Space plays and pauses. Left and Right step, Home and End jump to the first and last step. The slider scrubs, the menu next to it sets the speed.
- Scroll or pinch to zoom graphs, trees and points, and drag to pan. **Fit to view** puts it back.
- A very long run stops early. Try a smaller input.

## Save and share

- **Save** writes the algorithm, input and settings to an `.algo` file, in Documents unless you pick another folder. Open it again with **Open…** or from File Explorer.
- The link button copies a link that opens this algorithm with this input on its own.
