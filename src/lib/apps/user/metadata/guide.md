## Opening a file

- Open a JPEG, PNG, WebP or PDF with **Open a file…**, drop it on the window, or paste it.
- The details come in groups: camera, how the photo was taken, location, software and more. A location has a **Map** link next to it.
- For a file from your files, some rows have **Hex**: it opens Hex Viewer at the exact bytes that value comes from. The toolbar button opens the whole file there.

## Stripping

- **Strip & save** writes a clean copy next to the original, with `-clean` added to the name (`photo.jpg` becomes `photo-clean.jpg`). A dropped or pasted file asks where to save instead.
- The original stays as it is, and so do the pixels. The colour profile is kept, so colours don't shift.
- When a photo is turned by its metadata, **Keep orientation** keeps the copy upright.
- PDFs can be read but not stripped.
