## Three modes

- **Build** shows a maze being carved. Pick one of four ways to carve it (Backtracker, Prim, Kruskal, Wilson) and a size; each change builds a new maze. Each gives the maze a different feel, from long winding corridors to many short dead ends.
- **Solve** runs a search from the start to the exit. The searched cells fill in, then the shortest path shows. BFS spreads out evenly; A* heads towards the exit, so it usually searches fewer cells.
- **Play** is a race from the start in the top-left corner to the exit in the bottom-right.

**Speed** sets how fast building and solving play out, and **Skip** jumps to the end.

## Moving in Play

- **Keyboard:** the arrows or W, A, S, D move one cell. Hold Shift to run along the corridor to the next junction.
- **Swipe** on the maze (or drag with the mouse), or use the arrow pad on a phone: each runs to the next junction or dead end.

The clock starts with your first move. Each size keeps its best time. The restart button puts you back at the start of the same maze; **New maze** makes another.
