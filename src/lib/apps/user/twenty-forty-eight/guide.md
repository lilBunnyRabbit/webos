## How it works

- Every move slides all tiles as far as they go in one direction.
- Two tiles with the same number that run into each other merge into one with double the value.
- After each move a new 2 (sometimes a 4) appears in an empty cell.
- Reach a 2048 tile to win, then **Keep going** for a higher score if you like. The game ends when no move is left.

## Controls

- **Keyboard:** arrow keys or WASD.
- **Touch or mouse:** swipe or drag across the board.
- **Undo** (Ctrl+Z) takes back your last move.

## Score

Each merge adds the new tile's value to your score. Your best score is kept between games.
