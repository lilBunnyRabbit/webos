## The goal

Name the colour's six-digit hex code in five guesses or fewer.

## Guessing

- Type six digits, **0–9** and **A–F**, then press Enter or **Guess**. Backspace erases. On a phone, use the keypad under the board.
- Each digit gets a hint: **↑** the answer's digit is higher, **↓** it's lower, **✓** it's right.
- Your last guess shows next to the target, so you can compare the two colours.

## Reading a hex code

The six digits are three pairs: red, green and blue. The first digit of each pair matters most, so settle those first.

## Daily and practice

- **Daily** is one colour a day, the same for everyone. Game Hub ranks it by guesses used; a missed daily doesn't count.
- **Practice** gives a new colour each time you press **New puzzle**.
- When it's over, **Copy result** copies your hint grid and a link to the same colour for a friend.
