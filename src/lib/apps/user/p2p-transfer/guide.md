## Sending directly

- On the sending device: **Send**, **Direct**, add files with **Add file…** or **From device…**, then **Generate offer**.
- On the receiving device: **Receive**, **Direct**, then **Scan with camera** and point it at the offer.
- The receiver now shows an answer code. Scan it back on the sender, and the files start moving.
- Received files land in **Downloads**. The folder button next to each one opens it.

## When the camera won't read it

- **Take photo** reads a still from your phone's camera, which often focuses on a screen better.
- Every code has a copy button (and Share where your browser has it). Paste it into the box under the camera on the other device, then press **Connect**.

## Network and resume

- Both devices need a direct path: the same Wi-Fi, or one phone's hotspot. Mobile data to a home network often fails.
- Keep both screens on. If the link drops, what arrived is kept: press **Reconnect**, swap new codes, and it carries on. Reloading the page starts over.

## By light

No network at all. The sender picks one file (up to 2 MB), chooses **Steady** or **Fast**, and presses **Start sending**. The screen flashes a stream of codes. On the other device, pick **Receive**, **By light**, **Scan with camera**, and fill the view with the code. Missed codes only cost time. The file is saved to Downloads once it checks out; the sender keeps going until you press **Stop**.
