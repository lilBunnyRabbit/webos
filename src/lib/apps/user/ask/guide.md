## Two ways to ask

- **About your apps:** press **Read apps** and switch on what Ask may look up, like your shopping list or calendar. For each question it picks the one that fits, if any, reads it and answers from it. Under the answer, **Read** shows exactly what it looked at.
- **About a file:** press the folder button, or use **Open with** on a text file in File Explorer. Notes, logs, code, JSON and CSV all work. Answers come from the file only.

## Chatting

- Enter sends, Shift+Enter adds a line. **Stop** or Escape ends an answer early.
- Follow-up questions remember the chat. The bar above it shows how full the AI's memory is; when it fills up, start a **New chat**.
- Long files are cut short: only the first 16,000 characters fit.
- The speaker button next to Send reads every answer aloud as it arrives. Each answer also has its own copy and speak buttons.

## Good to know

- The first question downloads Chrome's AI model once. After that it works offline, and nothing leaves this device.
- In the Terminal, `ask` followed by a question does the same with the apps you switched on, or answers about text piped into it.
- The trash button explains how to remove the model from Chrome.
