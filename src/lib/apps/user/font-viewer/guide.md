## Opening a font

Open a TTF, OTF, TTC, WOFF or WOFF2 file from File Explorer or the desktop, or press **Open a font…**. You can also drop or paste a font file into the window. Nothing is installed: the font is only shown here.

## Looking at it

- Type in the sample box and drag the size slider (8 to 160 px).
- A collection (`.ttc`) holds several faces; pick one from the list next to the open button.
- Characters the font doesn't have are faded. Hover one to see its code.
- For a variable font, pick a named style or drag each axis; the reset button puts them back.

## Use as app font

**Use as app font** makes this font the UI or code font of WebOS. Change it back in Settings › Text & interface.
