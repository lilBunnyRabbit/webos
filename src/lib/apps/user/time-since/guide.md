## Counters

- **New counter** starts counting from now. Give it a name like "Last coffee".
- Click or tap a counter to see its history. Right-click it, or long-press on a phone, for Start, Stop, Rename, Delete and more.
- Started earlier? Open the counter and change **Started** to the real date and time.

## Reset or stop

- **Reset** ends the current run, saves it to the history, and counts again from zero.
- **Stop** ends the run and waits. **Start** begins a new run when you're ready.
- Reset by mistake? Delete the newest run under **Runs** and the counter carries on as before.

## History

Each counter shows its average, shortest and longest run, a bar for each recent run, and a map of the weekdays and hours you tend to reset. A badge appears when the current run beats your longest.

## On the desktop

On a computer, **Add to desktop** puts a counter on the desktop as a widget with its own reset button.

Your counters are saved in a file shown in the status bar. The Terminal can work with them too: type `since`.
