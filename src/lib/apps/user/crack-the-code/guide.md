## The goal

Find the secret code in as few guesses as you can. It's made of different digits, 0 to 9, with no digit used twice.

## Guessing

- Type the digits on your keyboard or click or tap the pad, then press **Transmit** or Enter. Backspace or **Erase** takes the last digit back.
- Each guess goes into the intercept log, newest first, with how many of its digits sit in the right place. A digit that's in the code but in the wrong place counts for nothing.
- Your guesses may repeat digits, even though the code never does. A guess of all one digit tells you whether that digit is in the code at all.

## Cases

- Pick the code length, 3 to 7 digits, in the toolbar. **New case** (F2) starts another code.
- **Declassify** gives up and shows the code. That case doesn't count in your statistics.
- The clock starts with your first guess. Close the window and the case is still open next time.
- **Statistics** shows, per length, the cases cracked, your fewest guesses and your best time. On a narrow window the chart button opens and closes them; on a phone you can also swipe them down.

## Daily case

Open it from Game Hub. It's kept apart from your regular case, so playing it never loses the one you had going.
