## Open

- Double-click a `.zip` in Files, or use the folder button to pick one.
- Click or tap a file to preview it. Folders open and close the same way.
- **Extract all…** asks for a folder and unpacks everything there. Tick files or folders first to extract only those.

## Create

- Add files and folders from WebOS, or from your device, with the buttons in the toolbar.
- **Deflate** makes the zip smaller; **Store** only bundles the files together.
- **Save…** asks where to put the zip.

## How it works

Type or paste text and see the repeats compression finds, and how much it saves. Point at a highlighted run, or tab to it, to see where it was copied from. A text file's preview has **How it compresses** to load it here.

## From the Terminal

`zip`, `zip list` and `unzip` do the same jobs. Big zips run in the background, with a progress bar you can cancel.
