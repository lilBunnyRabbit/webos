## Getting started

- Start typing on the blank page, or pick **File › New from template…** for a CV, cover letter, letter or report. Replace the placeholder text with yours.
- On a phone the **File** menu is the document's name at the top left.
- **Save** (Ctrl+S) writes a `.warren` file, in Documents unless you pick another folder.
- A Word `.docx` or a Markdown file opens as a new copy. Saving asks where to put it.

## Tools

- On a wide window the tools sit in a side panel: Text, Paragraph, Styles, Table, Picture, Page, Words, Spelling, Comments, Export and Outline.
- On a narrow window or a phone a bar above the page has the basics. **More tools** (the dots) opens the rest.
- Type `/` at the start of a line for a quick menu of headings, lists, tables, pictures and page breaks.
- Markdown shortcuts work as you type: `# ` for a heading, `- ` for bullets, `1. ` for numbers, `> ` for a quote.
- Right-click inside a table for rows, columns, merging and more.

## Pages

**Page** sets the paper size, orientation, margins, and a header and footer with page numbers. Page breaks go where you put them.

## Getting it out

- **Export for Word…** saves a `.docx`. **Print or save as PDF…** (Ctrl+P) prints or makes a PDF. **Export as Markdown…** saves the text as Markdown.
- **File › Version history…** keeps earlier versions of a saved document. Preview one, compare it with now, or restore it.

## Handy keys

- Ctrl+F find and replace. Ctrl+O open. Ctrl+Shift+S save as.
- Ctrl+Shift+F focus mode. Ctrl+Shift+8 shows ¶ marks.
- Ctrl+Shift+X strikethrough. Ctrl+\ clears formatting.

On a Mac, use Cmd instead of Ctrl.
