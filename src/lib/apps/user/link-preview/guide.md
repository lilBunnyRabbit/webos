## Loading a page

- **URL:** type an address and press **Fetch**. Only servers that let other sites read them answer, such as your own dev server (`localhost:5173`). Many public sites refuse.
- **HTML:** for any other page, open it, view its source, copy it all and paste it here, then press **Check** (or Ctrl+Enter). Nothing in it runs; only its tags are read.
- **File:** open a saved `.html` file. In Files, right-click one (or hold it on a phone) and pick Link Preview under **Open with**.

For pasted HTML or a file, set **Base URL** to the page's real address so relative image links resolve.

## Reading the results

- **Previews** shows the link card in each app. The badge on each says whether it unfurls; click or tap it to jump to that app's checks.
- **Checks** lists what each app needs and the tag to add or fix.
- **Image** shows the preview image's size and how each app crops it.
- **Raw** lists every tag the page has, with **Copy all as JSON**.

After you change your page, press the refresh button to fetch it again.
